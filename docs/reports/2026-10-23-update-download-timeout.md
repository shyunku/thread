# 2026-10-23 업데이트 다운로드 시간 초과

## 현상
- PC 2.2.0을 게시한 뒤, 설치된 2.1.4에서 업데이트 창이 "업데이트하지 못했어요 · 인터넷 연결을 확인한 뒤 다시 시도해 주세요"로 끝났다(2026-10-23 05:40경, 사용자 보고).

## 원인
- `apps/desktop/public/electron/e2ee/trustedUpdates.js`가 tuf-js에 `fetchTimeout: 10000`을 준다. 업데이트 확인(작은 메타데이터)이 멈추지 않게 하려던 값이다.
- tuf-js 6은 이 값을 `AbortSignal.timeout`으로 요청 전체(본문 포함)에 건다. 그래서 설치 파일 전체를 10초 안에 받지 못하면 중단된다.
- 2.2.0 설치 파일은 160.7MB(글꼴 포함으로 +9MB)다. 사용자 PC의 받기 속도는 약 10.8MB/s여서 약 15초가 걸린다. 2.1.4 설치 파일도 지금 받으면 15초가 걸린다. 예전 업데이트는 그때 속도가 더 빨라서 드러나지 않았다.
- 같은 설정으로 재현: 11.0초에 `TimeoutError`.

## 복구
- RMS: 버전 경로의 설치 파일만 `Cache-Control: public, max-age=31536000, immutable`로 내보낸다(메타데이터와 `releases.json`은 그대로 `no-store`). Cloudflare가 캐시해서 서버 부담과 거리 지연이 줄어든다. 다만 이번 병목은 받는 쪽 속도라 2.1.4는 여전히 10초 안에 받지 못한다.
- 앱 2.2.1: 응답이 10초 안에 오지 않거나 데이터가 30초 동안 오지 않을 때만 끊는 fetcher로 바꿨다. HTTP 오류는 tuf-js 오류 형식을 유지한다(다음 root 404 판정). 재현 조건에서 2.2.1 다운로드가 15.9초에 정상 완료됐다.
- 2.1.4 이하가 설치된 PC는 앱 안 업데이트가 계속 실패할 수 있다. 사이트(https://site.threadapp.kr)에서 2.2.1을 직접 받아 설치한다. 데이터는 그대로 남는다.

## 개선
