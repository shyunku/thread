## 설계 · 결정

- 서버 변경 없음: v3 서버는 암호화된 객체만 본다. 이름은 할 일과 같은 방식의 앱 행(`entityType: "deviceName"`, `entityId`: 멤버십 기기 id, `fields.name`)으로 암호화해 동기화한다. 기기 레코드(공개키 · 역할)는 바꾸지 않는다.
- 위험: 2.3.0 이하 PC와 모바일 beta.4 이하는 모르는 종류의 행을 만나면 목록 전체가 멈춘다. 그래서 2단계로 낸다(사용자 결정): 2.4.0은 건너뛰기(77.2)와 화면만, 이름 저장은 모든 기기가 업데이트된 뒤 2.5.0에서 켠다.
- 기본 이름(사용자 결정): 모델명. 폰은 모델명(예: Galaxy S24), PC는 "Windows PC". 같은 이름이 여럿이면 짧은 기기 id를 같이 보인다.
- 바꾸는 곳(사용자 결정): 쓰기 기기 어디서든. 읽기 전용 기기는 보기만. PC는 지금 주 기기만 기기 목록을 보는데, 모든 PC에서 보이게 바꾼다.
- 해제 · 복구로 빠진 기기의 이름은 표시하지 않는다(현재 멤버십 기준). 이름 바꾸기는 patch만 쓴다(삭제 후 재생성은 `ENTITY_RECREATE_REVIEW_REQUIRED`).
