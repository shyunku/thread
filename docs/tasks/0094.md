## 정책

| 상황 | 결과 |
| --- | --- |
| 다른 칸을 고침 | 최신 버전 위에 내가 바꾼 칸만 다시 얹어 보낸다. 둘 다 남는다. |
| 같은 칸을 고침 | 서버에 먼저 도착한 값이 남고 늦은 쪽의 그 칸 변경은 버린다. |
| 서버에서 이미 삭제됨 + 내 편집 | 편집을 버린다(삭제 유지). |
| 내 삭제 + 서버 편집 | 최신 버전 위에 삭제를 다시 적용한다(삭제 유지). |
| 같은 값으로 고침 | 충돌 아님. 그대로 둔다. |

- 판정은 기존 `outboxReview.js`의 `fieldStatus`(base/local/current 비교)를 그대로 쓴다: `LOCAL_ONLY`는 로컬 값, `REMOTE_ONLY`·`FIELD_CONFLICT`는 서버 값.
- 서버·암호문 형식은 바꾸지 않는다. 합치기는 기기에서 복호화한 뒤 한다(E2EE).
- 버린 값은 따로 보관하지 않는다(되돌리기 없음).
- 모바일(#86.3)은 #82 공용 코어로 같은 로직을 쓴다.
