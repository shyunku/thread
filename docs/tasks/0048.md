## 보호된 LDK 파일 영속화 — 2026-09-08 19:02 (KST)

- LocalVault가 environment/accountId/vaultId의 canonical hash 디렉터리에 OS 보호된 ldk.protected 및 암호화 DB를 보관한다. 파일·디렉터리는 새로 만들 때 exclusive 처리하여 기존 보관함을 덮어쓰지 않는다.
- 초기화 성공 marker는 키 파일 fsync 및 DB 스키마 생성·close 이후 마지막에 기록한다. 중단/키 분실/손상 시 원본을 유지하고 VAULT_RECOVERY_REQUIRED로 중단한다. 키 자동 재생성·원본 삭제·자동 복구는 하지 않는다.
- 생성·재열기, 키 분실 시 DB 바이트 보존, 불완전 초기화 거부, 계정/환경/보관함 격리 및 키 파일 바꿔치기 거부, OS 보호 unavailable 테스트 5개 통과. 전체 synthetic 보안 테스트 17개 통과.
- 실제 Electron 43.6.0 Windows x64의 safeStorage/DPAPI로 키 파일 영속화·재열기 및 암호화 DB 평문 미노출 smoke 통과. 테스트 전용 임시 폴더만 사용했다.
- 이번 모듈은 기존 로그인/Sync v2에 아직 연결하지 않았다. app runtime 사용자는 VaultSession 재인증 후에만 open해야 한다. 기존 설치본은 재빌드하지 않았다.

## 잠금 해제 구현 — 2026-09-08 20:09 (KST)

사용자가 Windows Hello/Touch ID 우선 + 별도 보관함 비밀번호 대체를 승인했다. Thread 자체 PIN은 추가하지 않는다. 두 방법을 화면에 표시하며 인증 취소 후 다른 방법을 자동 시도하지 않는다.

- 비밀번호 생성 최소 12자. worker Argon2id(64 MiB, 3회) + XChaCha20-Poly1305 및 scope AAD로 LDK를 보호한다. OS/비밀번호 양쪽으로 같은 암호화 DB를 연다. 비밀번호 자체는 파일에 저장하지 않으며 손상/오입력 시 원본을 초기화하지 않는다. JS 문자열 완전 소거나 같은 OS 사용자 권한의 악성 프로세스 차단을 보장하지 않는다.
- Windows HWND 기반 UserConsentVerifier helper 및 macOS Touch ID adapter 추가. helper 컴파일·beforePack 복사 hook 통과, 현재 PC availability=available. Windows 빌드에는 VS C++ 도구와 C++/WinRT Windows SDK가 필요하다.
- VaultUnlock은 방법 선택·로그인 비밀번호와의 차이 안내·확인 입력·취소/실패 처리를 제공한다. 아직 로그인/홈/Sync v2에 연결하지 않은 컴포넌트다. vault/ IPC 인수 로깅 차단만 추가했으며 전체 로그 감사 #56은 미완료다.
- React 56개, Electron Node-mode 비밀번호/DB 테스트 2개 통과. 후자에서 crashpad 접근 거부 경고가 있었지만 테스트 종료 코드는 0이었다. 새 설치본은 만들지 않았다.
- 사용자 검증 대기: apps/desktop에서 `pnpm exec electron tests/osAuth.manual.cjs` 실행. 버튼으로 인증 성공(VERIFIED)과 취소(성공으로 처리되지 않음)를 각각 확인한다. 별도 임시 프로필만 사용하고 실제 계정/DB/env를 읽지 않는다. 테스트 임시 프로필은 남을 수 있다.
- 실제 앱 연결·OS 잠금·복구/변경 UI·macOS 실기기 검증은 미완료. #48 WIP 유지. #57 이전 운영 마이그레이션/평문 삭제는 하지 않는다.
- production React 빌드 성공(ESLint 경고 있음). 첫 시도는 sandbox의 E: build 쓰기 EPERM으로 실패했고 승인된 권한으로 재실행해 통과했다. 설치 패키징 및 사용자 인증 성공/취소는 별도 검증이다.
