## 릴리스 alert 발행·수신 구현

- 시작: 2026-09-07 16:03 (KST)
- 완료: 2026-09-07 18:05 (KST)
- 상태: 🟢 DONE

RMS에서 검증된 릴리스와 실제 설치 파일을 확인한 뒤 alert 상태를 영속화하고, API의 Sync v2 WebSocket으로 현재 접속한 데스크톱에 즉시 알린다. 데스크톱은 시작·로그인·재접속·절전 복귀와 30초 주기 확인으로 누락된 알림을 복구하며 현재 버전보다 새로운 릴리스만 표시한다.

Beta는 저장용 릴리스로 일반 업데이트에서 제외한다. `Not compatible with previous`는 verified 비-Beta 릴리스에만 허용하며, 해당 경계를 지난 구버전 데스크톱은 설치 파일을 자동 다운로드한다. 앱을 강제 종료하거나 설치하지 않고 사용자가 작업을 보존한 뒤 설치 파일 위치를 열어 실행하도록 한다.

RMS 시작 시 `version_master.not_compatible` 컬럼을 기본값 `false`로 자동 추가한다. 기존 행은 보존되며 반복 실행해도 안전하다.

검증:

- Desktop 테스트 51개, Admin 테스트 6개 통과
- RMS alert·권한·스키마 및 기존 청크 업로드 테스트 통과
- API v1/v2와 실제 MySQL·WebSocket 2개 연결 통합 테스트 통과
- Linux API 빌드 및 Windows Desktop 1.1.2 NSIS 빌드 통과
- 생성 파일: `apps/desktop/dist/Thread Setup 1.1.2.exe`

운영 반영 시 API, RMS, Admin Site를 재배포하고 RMS DB 계정에 `ALTER` 권한이 있는지 확인한다.
