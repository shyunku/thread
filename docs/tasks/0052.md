### 52.7.1–52.7.2 검증 — 2026-09-10 17:44

- 서명 전 단일 항목의 conflict만 대상으로 사용자가 local/current 전체 값을 선택한다. local은 최신 검증 버전 기준 새 mutation/counter의 미서명 outbox를 만들며, current는 검증된 사본으로 overlay를 복원한다. 부분 필드 병합은 아니다.
- 기존 draft와 선택 결과는 encrypted recovery에 보존한다. outbox 변경/overlay/새 counter/결정을 한 transaction에 넣고 실패 시 모두 rollback한다. 동일 선택 재시도는 멱등이며 다른 선택으로 재사용할 수 없다.
- 서명된 요청, 삭제/누락된 현재 항목, 복수 항목, 종속 편집, 변경된 비교 revision은 거부한다. UI는 확인 체크 이후에만 선택하며 서버 전송을 직접 실행하지 않는다.
- E2EE/TUF 125/125, UI 11/11, renderer build 통과(기존 ESLint 경고). 실제 사용자 데이터/운영 서버/이관은 건드리지 않았다.
- 복구 자료를 탐색/되돌리는 최종 UX와 signed/불확실 ACK/복수·종속 선택은 아직 미완료다. 52.7 전체 WIP 유지.
