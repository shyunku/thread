MySQL을 호스트 127.0.0.1:3309에 게시하여 SSH 터널로 연결할 수 있도록 한다.

변경: compose.yaml의 mysql.ports에 `127.0.0.1:3309:3306` 추가. 컨테이너 간 연결은 기존 mysql:3306을 사용하고 mysql-data 볼륨을 유지한다.

검증: `docker compose --env-file .env.example config --quiet` 종료 코드 0. 로컬 Docker 사용자 설정 접근 경고가 있었지만 Compose 구성 검증은 성공했다. 실제 컨테이너 재생성·원격 SSH 연결은 수행하지 않았다.

서버 반영: `docker compose up -d --no-deps mysql`. 포트 적용 과정에서 MySQL 컨테이너가 재생성되어 잠시 연결이 중단될 수 있다.

PC에서 터널: `ssh -N -L 127.0.0.1:3309:127.0.0.1:3309 ec2-user@<EC2_HOST>`. SSH 키가 필요하면 `-i <KEY_PATH>`를 추가한다. DB 도구는 로컬 127.0.0.1:3309와 기존 MySQL 계정으로 접속한다.
