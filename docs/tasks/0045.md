## 구현·검증 — 2026-09-08 14:50 (KST)

- Electron 23.1.0 → 43.6.0 및 사용하지 않는 @electron/remote 제거. 44.2.0을 먼저 검증했으나 ia32 지원 중단을 확인해 기존 Windows 설치 대상을 유지하는 43.6.0으로 변경했다. 제품 버전은 1.1.3 유지.
- 독립 설치에서 루트 .npmrc가 적용되지 않아 isolated/hoisted 경로가 혼합되고 CRA ESLint 충돌이 발생했다. desktop/.npmrc에 hoisted 정책을 명시하고 frozen-lockfile 재설치로 복구했다. 기존 의존성 디렉터리는 .tmp/desktop-deps-before-0045에 보존했다.
- keyProtection: 메인 전용 32바이트 키 envelope 보호 모듈. OS 저장소 unavailable·Linux basic_text/unknown은 거부하며, 보호된 envelope 안의 계정/dev/prod/purpose를 검사한다. 기존 DB나 로그인에 연결하지 않았다. 파일 영속화·보관함 잠금은 #48 범위다.
- Electron 43.6.0 Windows x64 synthetic: 실제 OS 암호화/복호화, 손상·다른 계정 거부, sqlite3 5.1.4 메모리 DB 읽기/쓰기 통과.
- Electron 43.6.0 synthetic renderer isolation: sandbox, IPC 소유권·updater 역할, OAuth bridge 차단 및 postMessage 통과.
- 최종 hoisted 설치 후 Jest 11 suites / 52 tests, keyProtection/windowSecurity 10 tests 통과. production renderer 빌드 성공(기존 ESLint 경고).
- 테스트는 별도 OS 임시 프로필과 임의 키/메모리 DB만 사용했다. 실제 계정 키·사용자 DB·비밀 env를 조사하지 않았다. 테스트 임시 프로필은 OS temp에 남을 수 있다.

## 사용자 확인 게이트 — WIP 유지

1. 루트에서 `pnpm run dev:desktop`: 일반/Google 로그인, 창·트레이, 테스트 할 일 편집·재시작, 설정·달력을 확인한다. 연동 취소 재시도 오류는 #44에 기록된 사용자 보류 사항이다.
2. Electron 43은 macOS 12 이상이 필요하다. 사용자가 최소 지원 상향을 승인하여 build.mac.minimumSystemVersion=12.0을 명시했다. 운영 배포는 별도다.
3. Windows DPAPI는 Windows Hello 재인증이 아니다. OS 재인증 어댑터·잠금/절전 실기기 검증은 아직 구현/검증하지 않았다. Windows/macOS 재인증 구현 및 지원 범위를 확정해야 한다.
4. ia32 설치 파일 생성·덮어쓰기, macOS Keychain·서명 연속성, Linux 보안 저장소는 미검증. 단위 테스트의 플랫폼 모의 결과와 실기기 결과를 구분한다.

아직 E2EE 데이터 보호가 활성화된 상태가 아니며 #45는 DONE이 아니다. 다음 사용자 데이터/키 작업은 이 게이트 후 진행한다.
