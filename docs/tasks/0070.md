## 확정안

### 탭 구성
일반 · 데이터 · 사용자 맞춤 · 계정 · 시스템 · 정보. 빈 탭은 허용한다.

| 탭 | 내용 |
| --- | --- |
| 일반 | 시작할 때 보기(리스트/캘린더/타임라인), 주 시작 요일(일/월), 시간 표시(12/24시간). 테마(다크/라이트/시스템)는 후순위 |
| 데이터 | 아래 별도 정리 |
| 사용자 맞춤 | 보류. 레이아웃 조정은 설정이 아닌 화면 내 조작으로 넣을 수 있음 |
| 계정 | 이메일·로그인 방식·이 기기 이름 표시. OAuth가 없는 기존 계정은 Google 계정 연결 제공(70.2 확인 결과에 따름). 로그아웃은 맨 아래 별도 |
| 시스템 (신규) | 부팅 시 자동 시작, 창 닫으면 트레이로, 하드웨어 가속(변경 시 재시작 후 적용 표시) |
| 정보 | 버전, 업데이트 확인 버튼, 베타 버전 받기(현재 빌드 설정 `enableBetaUpdate`를 사용자 설정으로), 라이선스, 개인정보처리방침 링크(#69), 문의. 기존 개발자 문구 정리 |

업데이트 확인 방식 옵션은 두지 않는다.

### 용어
화면에서 보관함, 키 회전, 키 세대, identity, 서명, 재인증 같은 말을 쓰지 않는다. 한 화면의 설명은 한두 문장으로 제한한다.

| 현재 | 변경 |
| --- | --- |
| 복구 자료 / 백업 수단 | 복구 키 (`.trec` 파일 + 코드) |
| 기기 연결, 보관함 지문 / 요청 지문 | 새 기기 추가, 확인 코드 |
| 암호화 백업 | 데이터 백업 |
| 기기·키 관리, 기기 해지와 키 회전 | 연결된 기기, 기기 해제 |
| 암호화 갱신, 기존 데이터 재암호화 | 기기 해제 과정의 한 단계로 통합 |
| 데이터 잠그기 | 앱 잠금 |
| 복구 자료 · 자료 N (이관 검토) | 이전 버전 데이터 검토 |

| 경계 | 내용 |
| --- | --- |
| 동작 보존 | 화면·문구·배치만 바꾼다. 복구·기기 연결·백업·해제·재암호화의 암호 처리와 서버 계약은 바꾸지 않는다 |
| 위험 작업 | 기기 해제·복구 키 재발급처럼 되돌릴 수 없는 작업은 결과를 쉬운 말로 먼저 보여 주고 확인을 받는다 |
| 데스크톱 실행 | 앱 실행 검증은 secure 로그 모드로 한다 |
