문제

  • 로그인 후 첫 화면(데이터 열기, 잠금, 새 계정 설정, 이관)에는 메인 화면의 상단 바가 없어서, 필수가 아닌 업데이트를 알 방법이 없었어요. 연결 전 기기는 업데이트를 못 받는 상태가 됨.

바꾸는 것

  • 이 화면들의 제목 표시줄 오른쪽(최소화 버튼 왼쪽)에 메인 화면과 같은 초록 업데이트 버튼을 넣어요. 누르면 같은 업데이트 안내창이 열려요.
  • 작은 잠금 화면(380px)은 아이콘만 보여요.
  • 업데이트가 없으면 아무것도 안 보여요.

그대로인 것

  • 업데이트 안내창, 다운로드·설치 동작, 필수 업데이트는 자동으로 열리는 것.

정해 줘야 할 것

  • 이대로 넣을지. (대안: 시작할 때 새 버전이 있으면 안내창을 한 번 자동으로 띄우기)
