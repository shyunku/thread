✓ 새 기기를 추가했어요.

새 기기가 데이터를 받아오기 시작했어요. 기기 목록에서 언제든 해제할 수 있어요.

QR·파일로 연결

지금 앱의 "새 기기 추가" 4단계와 같아요

연결 코드 복사 → 새 기기의 QR 이미지나 요청 파일 열기 → 확인 코드 비교 → 승인 파일 저장.

복구 코드로 연결할 때는 쓰던 기기를 쓰지 않아요.

바꾸는 것

  • 연결 방식: 서버가 요청과 승인을 대신 전달해요. 사용자는 두 화면의 6자리 숫자가 같은지만 보고 양쪽에서 "같아요"를 눌러요. 코드 입력·QR 캡처·파일 옮기기가 없어져요. (보안 설계: protocol/v3-relay-pairing.md)
  • 새 기기 화면: 시작에서 "쓰던 기기로 / 복구 코드로"를 고르고, 설정의 단계 대화상자와 같은 진행 바·버튼으로 이 기기에서 할 일만 보여 줘요.
  • 쓰던 기기(설정 → 새 기기 추가): 4단계에서 3단계로. 열면 새 기기를 기다리고, 숫자 비교 후 Windows Hello로 승인하면 끝.
  • QR·파일 방식은 양쪽 모두 "QR·파일로 연결" 링크 뒤로 숨겨서 남겨요.
  • 잠금 방법 설정(보관함 만들기)을 첫 단계로. Windows Hello가 없는 PC는 비밀번호만.
  • 복구 코드 경로는 한 화면의 체크박스·버튼 7개를 5단계로 나누고, 결과(다른 기기 연결 해제)를 첫 단계에서 먼저 확인받아요.

그대로인 것

  • 기기 키, 멤버십 서명, 승인 데이터 암호화 형식. 서버는 여전히 내용을 볼 수 없어요.
  • 요청은 10분 뒤 만료, 승인 전 본인 확인.
  • 창 크기(528×820)와 제목 표시줄.

정해 줘야 할 것

  1. 시작 화면의 "다른 계정으로 로그인" 링크를 넣을지. 잠금 화면에선 뺐지만, 여기선 잘못된 계정으로 들어오면 빠져나갈 길이 없어요.
  2. "새 계정 데이터 설정"과 "데이터 보호 업데이트(이관)" 화면도 같은 스타일로 바꿀지. 둘 다 아직 예전 UI예요.
