하단 시간 완료 항목 하단 hover 리스트 완료 항목 제목 편집 focus

확정 (구현 완료)

  • 하단 시간: 아래 목록의 모든 할 일에 "2시간 남음"/"3시간 지남". 지난 건 빨간색, 완료한 할 일은 회색으로 시간만 표시.
  • 하단 완료 항목: 취소선 + 50% 흐리게.
  • hover 연결: 양방향. 아래 목록 ↔ 왼쪽 리스트 ↔ 캘린더 칸.
  • 제목 편집: A, 테두리 없음.

새로 바뀌는 것 (확인 필요)

  • 리스트 완료 항목 흐리게: 완료됨 그룹의 할 일 카드 전체를 흐리게 합니다(지금은 제목 취소선만). hover하면 그대로 흐린 상태에서 테두리만 밝아집니다.
  • 그룹 접기: "해야할 일"/"완료됨" 제목을 누르면 접히고 펼쳐집니다. 화살표가 아래(펼침)/오른쪽(접힘)으로 돌아갑니다. 기본은 해야할 일 펼침, 완료됨 접힘. 왼쪽 리스트의 그룹 제목을 눌러 보세요.
  • 접힘 상태는 앱이 켜져 있는 동안 카테고리를 옮겨도 유지하고, 앱을 다시 켜면 기본값으로 돌아갑니다.

그대로인 것

  • 캘린더 칸 안의 할 일 모양, 날짜 선택 방식, 다른 버튼의 키보드 focus 표시.
  • 완료됨이 접혀 있어도 "완료한 할 일 더 보기"는 펼쳤을 때 지금처럼 동작합니다.

정해 줘야 할 것

  • 리스트 완료 항목을 얼마나 흐리게 할지(60% / 45%).
  • 접힘 상태 기억 방식이 위 설명대로 괜찮은지.
