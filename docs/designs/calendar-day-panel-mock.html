하단 시간 완료 항목 하단 hover 제목 편집 focus

바뀌는 것

  • 남은/지난 시간: 캘린더 아래 목록의 각 할 일 오른쪽에 "3시간 남음" 또는 "2시간 지남"을 표시합니다. 지난 건 빨간색입니다. 완료한 할 일에는 시간을 표시하지 않습니다.
  • 완료 항목: 지금은 점만 초록색입니다. 바꾸면 제목에 취소선이 생기고 줄 전체가 흐려집니다(50%).
  • 하단 hover: 아래 목록의 할 일에 마우스를 올리면 왼쪽 리스트와 캘린더 칸에서 같은 할 일이 강조됩니다. 반대로 리스트나 캘린더에서 올려도 아래 목록의 해당 줄이 강조됩니다. 아래 목록에 직접 마우스를 올려서 확인할 수 있습니다.
  • 제목 편집 focus: 할 일을 펼쳐 제목 칸을 누르면 지금은 파란 테두리가 생깁니다. A는 테두리 없이 커서만, B는 테두리 대신 얇은 밑줄을 둡니다.

그대로인 것

  • 캘린더 칸 안의 할 일 모양, 리스트 모양, 날짜 선택 방식.
  • 키보드로 이동할 때 다른 버튼의 파란 테두리(접근성 표시)는 그대로 둡니다. 제목 입력칸만 바꿉니다.

정해 줘야 할 것

  • 제목 편집 focus를 A(없음)와 B(밑줄) 중 어떤 걸로 할지.
  • 완료한 할 일에도 시간을 보여 줄지(예: "완료"), 지금 시안처럼 숨길지.
  • hover 연결을 양방향(리스트·캘린더 → 아래 목록도 강조)으로 할지, 아래 목록 → 리스트·캘린더 한 방향만 할지.
