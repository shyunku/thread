동기화

문제

  • 다 동기화된 상태인데 바가 회색으로 비어 있어서 "아무것도 안 된" 것처럼 보임.

후보 (동기화 완료일 때만 다름)

  • A 지금: 회색 빈 바 + 흐린 "보낼 변경 0개".
  • B 초록으로 채움: 바를 초록으로 꽉 채우고 "모두 동기화됨 · 방금"으로 바꿈. 보낼 변경이 있으면 지금처럼 초록+주황으로 나뉨.
  • C 바 대신 체크: 완료일 땐 바를 없애고 "✓ 모두 동기화됨 · 방금"만 보여 줌. 바는 보낼 변경이 있거나 동기화 중일 때만 나타남.

같이 바뀌는 것

  • 동기화 중: 지금은 따로 표시가 없음. 바 위로 초록 빛이 흐르는 표시를 넣음(실시간 동기화가 들어가면 잠깐씩 보임).
  • 오프라인·충돌 검토 표시는 그대로.

정해 줘야 할 것

  • 완료 표시를 A/B/C 중 어떤 걸로 할지, "동기화 중" 흐르는 표시를 넣을지.
