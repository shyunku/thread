Play Console에 그대로 옮겨 적을 답과 문구다. 근거는 개인정보처리방침(`apps/web/site/src/pages/Privacy.js`)과 앱 코드다. 작업 기록은 [#92](../tasks/0092.md)에 있다.

갱신: 2026-10-28 (KST)

## 1. 데이터 보안 양식

### 1-1. 데이터 수집 및 보안

| 질문 | 답 |
| --- | --- |
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | 예 |
| 수집된 모든 사용자 데이터가 전송 중에 암호화되나요? | 예 (HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있는 방법을 제공하나요? | 예 (아래 2-3 계정 삭제 준비 후) |

할 일 내용(제목 · 메모 · 카테고리 · 하위 할 일 · 비밀 카테고리)은 **수집으로 신고하지 않는다**. 기기에서 종단간 암호화한 뒤 보내고 운영자가 읽을 수 없기 때문이다. Google 데이터 보안 도움말은 보낸 사람과 받는 사람만 읽을 수 있는 종단간 암호화 데이터를 신고 대상에서 뺀다([도움말](https://support.google.com/googleplay/answer/11416267)). 여기서 보낸 사람과 받는 사람은 같은 사용자의 기기들이다.

### 1-2. 수집하는 데이터 유형

모두 **공유하지 않음**(제3자에게 넘기지 않음), **수집 목적: 앱 기능 · 계정 관리**, **처리: 임시 처리 아님**.

| 데이터 유형 | 신고 | 필수/선택 | 근거 |
| --- | --- | --- | --- |
| 개인 정보 › 이름 | 수집 | 필수 | 가입 때 정하는 사용자 이름 |
| 개인 정보 › 이메일 주소 | 수집 | 선택 | Google로 가입 · 연결한 경우만 |
| 개인 정보 › 사용자 ID | 수집 | 필수 | 아이디, 계정 식별자, Google 계정 식별자 |
| 개인 정보 › 기타 정보 | 수집 | 선택 | Google 프로필 사진 주소(Google 연결 시) |
| 기기 또는 기타 ID | 수집 | 필수 | 앱이 무작위로 만든 기기 식별자와 기기 공개키(하드웨어 ID 아님) |
| 앱 활동 · 사용자 생성 콘텐츠 | 신고 안 함 | - | 종단간 암호화(1-1) |
| 위치 · 금융 · 건강 · 메시지 · 사진 · 오디오 · 파일 · 캘린더 · 연락처 · 웹 기록 | 수집 안 함 | - | 해당 없음 |
| 앱 정보 및 성능(비정상 종료 로그 · 진단) | 수집 안 함 | - | 출시판은 로그를 남기지 않고 분석 · 오류 수집 SDK 없음 |

비밀번호: 원문은 보내지 않고 기기에서 바꾼 해시만 보낸다. 양식에 별도 항목이 없어 "사용자 ID"와 같은 계정 관리 목적에 포함된다.

### 1-3. 보안 관행

## 2. 앱 설정 항목

### 2-1. 앱 액세스

"일부 기능 또는 모든 기능이 제한됨"을 고르고 아래 안내를 적는다.

> 로그인이 필요한 앱입니다. 앱 첫 화면의 "처음이신가요? 가입하기"에서 아이디와 비밀번호만으로 바로 새 계정을 만들 수 있습니다. 가입하면 이 기기의 잠금 방법(생체 인증 또는 화면 잠금)을 고르고 복구 코드를 복사 · 저장하는 단계가 나옵니다. 복구 코드는 아무 곳에 저장하셔도 되며, 이후 모든 기능을 쓸 수 있습니다.
> 아래 계정으로도 로그인할 수 있지만, 이 계정은 처음 연 기기에서만 열리도록 암호화되어 있어 이미 다른 기기에서 쓴 뒤라면 새 기기 승인이 필요합니다. 가능하면 새 계정 만들기를 이용해 주세요.

심사용 계정을 따로 적는다면: 데이터가 없는 새 계정을 만들어 두고 **어느 기기에서도 열지 않은 상태**로 제출한다. 처음 연 기기에서 보관함이 만들어지므로, 한 번 쓴 뒤에는 다음 심사 전에 새 계정으로 바꾼다. 이유: 종단간 암호화라 새 기기는 기존 기기의 승인이나 복구 코드 · 복구 파일이 있어야 열린다.

### 2-3. 계정 삭제 (출시 전 필요)

Play는 앱 안에서 계정을 만들 수 있으면 **앱 안에서 계정 삭제를 시작하는 경로**와 **삭제를 요청하는 웹 링크**를 둘 다 요구한다. 지금은 둘 다 없다(방침 6항: 문의 메일로 요청). 준비할 것:

- 앱 설정 › 계정에 "계정 삭제" 항목(앱 안에서 바로 지우거나, 최소한 삭제 요청 화면으로 안내).
- 사이트에 계정 삭제 요청 안내 페이지(예: `https://site.threadapp.kr/delete-account`)와 그 링크를 데이터 보안 양식에 입력.
- 개인정보처리방침 6항 문구 갱신.
