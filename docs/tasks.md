# Tasks

진행 중인 태스크만 이 문서에 둔다. 완료된 태스크는 [완료 기록](tasks_done.md)과 `tasks/done/`으로 이동한다. 번호는 두 목록 전체에서 증가하며 재사용하지 않는다.

완료 조건은 짧은 판정 기준만 기록한다. 상세 변경·검증 결과와 미검증 범위는 Index 번호에 걸린 태스크 기록에서 확인한다.

태스크 기록은 요약된 TODO/WIP/VFY/DONE 표 중심으로 유지한다. #45~#58은 사용자 요청으로 통일했으며, 다른 과거 태스크는 수정할 때 적용한다. 긴 진행 이력·불필요한 세분화는 지양하고 세부 완료와 전체 완료를 구분한다.
